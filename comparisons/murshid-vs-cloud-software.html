Frequently Asked Questions: Offline-First vs. Cloud

💾 How do I back up my patient records if Murshid works offline?

Murshid includes an automated, encrypted backup tool (`DataBackupHelper`). With one tap, you can export a secure, password-encrypted backup file to an external drive, USB key, or your personal private cloud storage, and restore it to a new device in seconds without vendor dependency.

⚡ Why is the local Isar database faster than cloud platforms?

The Isar NoSQL database is engineered in Rust and C++ specifically for mobile and desktop performance. It accesses data directly from local device memory in sub-milliseconds without waiting for trans-continental HTTP server round-trips.

🌍 Can I manage international patients residing in other countries?

Yes. Murshid is architected for global practice: it natively supports English and Arabic, converts seamlessly between Metric and Imperial measurements, supports all global currencies for invoicing, and syncs meal plans with patients via the companion app worldwide.

⚖️ What is Murshid's clinical regulatory boundary?

Murshid is strictly an administrative, computational, and documentation assistant. It is NOT a Software as a Medical Device (SaMD) and does not provide automated clinical diagnoses. The licensed dietitian retains full professional discretion and responsibility for all patient evaluations and dietary plans.
